Experimental Prototype Usability Issue Log

Purpose

This document records issues identified during internal validation of the low-fidelity experimental prototype.

The issue log is maintained separately from the prototype specification so that design changes remain traceable.

Issues should be recorded before they are fixed whenever possible.

---

Validation Rule

An issue should not be marked Resolved solely because the visual appearance has changed.

It should be marked resolved only after the relevant interaction or experimental behaviour has been tested again.

Experimental-blocking issues must be revalidated before the prototype proceeds to participant-facing pilot testing.
