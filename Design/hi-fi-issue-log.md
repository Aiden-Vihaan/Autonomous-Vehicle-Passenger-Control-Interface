High-Fidelity Prototype Issue Log

1. Purpose

This document records issues discovered during high-fidelity prototype validation.

The issue log provides traceability between:

Problem
→ Assessment
→ Design Change
→ Revalidation

No issue should be silently changed without documentation when the change could affect the experimental prototype.

---

2. Severity Levels

Severity| Meaning
P0| Critical — prevents completion or compromises experimental validity
P1| Major — substantially affects interaction or interpretation
P2| Moderate — noticeable but does not prevent completion
P3| Minor — low-impact issue

---

5. Experimental Integrity Issues

These issues receive special attention because they may affect interpretation of experimental outcomes.

Examples include:

Different event timing between conditions
Different vehicle response between conditions
Different measurement wording
Condition label visible to participant
Different observation duration
Different visual prominence unrelated to explanation content
Incorrect explanation assigned to scenario

Any such issue should be investigated before participant testing.

7. Change Control

A design change must be documented if it changes:

- experimental condition;
- explanation content;
- event timing;
- vehicle response;
- measurement sequence;
- participant instructions;
- question wording;
- interaction behaviour;
- visual salience of experimental information.

Minor purely cosmetic corrections may also be recorded when useful for traceability.

---

8. Revalidation Rule

After resolving an issue:

1. Re-run the affected interaction.
2. Re-run the surrounding interaction states.
3. Check the experimental condition.
4. Check downstream measurements.
5. Record the result.

An issue is not considered closed merely because the visual defect has been corrected.

10. Definition of Done

The issue log is ready for pilot preparation when:

- [ ] All identified issues are documented.
- [ ] No unresolved P0 issue remains.
- [ ] P1 issues are resolved or justified.
- [ ] Experimental integrity issues have been reviewed.
- [ ] Resolved issues have been revalidated.
- [ ] Final prototype version is recorded.
