Release Objective

Release 1.0 represents the completed research and design framework for the autonomous-vehicle passenger control interface.

The project integrates:

- product requirements
- Human Factors research
- theoretical framework
- experimental methodology
- interface architecture
- accessibility
- explainable AI
- data architecture
- analysis pipeline
- research interpretation
- final manuscript
- reproducibility
- portfolio documentation

---

Final Research Question

«How does the presentation of explanations for unexpected autonomous-vehicle behaviour affect passenger understanding, trust, and cognitive workload?»

---

Final Experimental Conditions

A — No explanation
B — Minimal explanation
C — Contextual explanation

---

Final Contribution

This project develops a Human Factors framework for designing and experimentally evaluating passenger-facing explanations of unexpected autonomous-vehicle behaviour, balancing:

- understanding
- calibrated trust
- cognitive workload
- accessibility
- safety

---

Data Status

The repository contains a synthetic demonstration dataset.

It is not empirical participant data.

The analysis infrastructure is designed so that genuine participant data can replace the synthetic dataset without changing the conceptual research framework.
