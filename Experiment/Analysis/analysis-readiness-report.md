Day 31 — Analysis Readiness Report

Project: Autonomous Vehicle Passenger Control Interface
Experimental Version: EV-1.0
Research Phase: Data Validation and Analysis Preparation

---

1. Research Objective

The empirical study investigates whether different forms of explanation for unexpected autonomous-vehicle behaviour influence:

1. passenger comprehension;
2. trust;
3. cognitive workload;
4. perceived understanding;
5. response behaviour.

The primary research question is:

«How does the presentation of explanations for unexpected autonomous-vehicle behaviour affect passenger understanding, trust, and cognitive workload?»

---

2. Experimental Manipulation

The independent variable is explanation condition:

A — No explanation
B — Minimal explanation
C — Contextual explanation

The experimental version is fixed at:

EV-1.0

---

3. Primary Outcome

Comprehension

Comprehension is the primary dependent variable because the central Human Factors question concerns whether explanation presentation helps passengers understand autonomous-vehicle behaviour.

The primary analysis compares comprehension across explanation conditions according to the predefined analysis plan.

---

4. Secondary Outcomes

Secondary outcomes include:

- response time;
- trust;
- workload;
- perceived understanding;
- task success;
- interaction errors.

Qualitative observations are analyzed separately from quantitative outcomes.

---

5. Analysis Framework

Stage 1 — Dataset Description

The first analysis stage reports:

- number of participants represented in the dataset;
- number of trials;
- number of observations per condition;
- missing observations;
- technical issues;
- protocol deviations.

No participant count is stated here until it is supported by the actual dataset.

---

Stage 2 — Descriptive Analysis

For each explanation condition, descriptive statistics will be calculated for applicable continuous variables.

Depending on the final dataset structure, these may include:

- mean;
- median;
- standard deviation;
- interquartile range;
- minimum;
- maximum.

For categorical variables:

- frequency;
- percentage.

---

Stage 3 — Comprehension Analysis

The primary outcome is evaluated first.

The analysis examines whether comprehension differs across:

A vs B vs C

If the experimental design and sample size justify inferential testing, an appropriate repeated-measures or within-subject method will be selected according to the final data structure.

If inferential assumptions are not adequately supported, the analysis will emphasize descriptive patterns and effect sizes rather than forcing a statistical test.

---

6. Response-Time Analysis

Response time is analyzed as an indicator of behavioural efficiency.

The analysis considers:

- central tendency;
- variability;
- condition differences;
- technically invalid measurements;
- protocol-related interruptions.

Response time is not interpreted as workload by itself.

---

7. Trust Analysis

Trust scores are examined across explanation conditions.

The analysis asks whether explanation presentation is associated with differences in reported trust.

The project does not assume that higher trust is automatically better.

A Human Factors interpretation considers whether increased trust is consistent with understanding and appropriate calibration.

---

8. Workload Analysis

Workload is analyzed as a distinct construct.

The analysis examines whether explanation presentation is associated with differences in reported cognitive workload.

A reduction in workload is not assumed in advance.

Unexpected or null findings are retained.

---

9. Perceived Understanding

Perceived understanding is analyzed separately from objective comprehension.

This distinction is important because a participant may:

- believe they understand the system;
- while answering incorrectly,

or:

- answer correctly;
- while reporting low confidence in their understanding.

Therefore:

Objective comprehension
        ≠
Perceived understanding

The relationship between these measures may provide additional insight into passenger interaction with autonomous systems.

---

10. Trust Calibration

Where the dataset permits, trust and comprehension are interpreted jointly.

The analysis avoids equating:

higher trust = better outcome

Instead, the Human Factors objective is appropriate trust.

A useful conceptual relationship is:

System behaviour
        ↓
Explanation
        ↓
Passenger interpretation
        ↓
Understanding
        ↓
Trust judgement
        ↓
Passenger response

---

11. Qualitative Analysis

Qualitative observations are reviewed separately.

Relevant observations may concern:

- confusion;
- hesitation;
- explanation interpretation;
- interaction difficulty;
- unexpected system behaviour;
- perceived clarity;
- accessibility issues;
- technical problems.

Qualitative notes are not converted into quantitative findings without a defined coding procedure.

---

12. Protocol Deviations

Protocol deviations are reported transparently.

For every substantive deviation, the analysis records:

- what occurred;
- when it occurred;
- which trial was affected;
- why it occurred;
- whether the affected observation remains interpretable;
- whether sensitivity analysis is required.

---

13. Technical Failures

Technical failures are distinguished from participant behaviour.

Examples:

Interface failure
≠
Participant interaction error

Measurement failure
≠
Low comprehension

This distinction protects the validity of the empirical interpretation.

---

14. Null Results

A null result is considered a legitimate research outcome.

The study will not modify hypotheses after observing the data merely to obtain a significant result.

If explanation condition produces little or no measurable difference, the result will be reported as such and discussed in relation to:

- experimental sensitivity;
- explanation design;
- scenario characteristics;
- sample size;
- measurement limitations;
- prior literature.

---

15. No Fabricated Statistics

The following values will only be reported after calculation from actual observations:

- sample size;
- means;
- medians;
- standard deviations;
- percentages;
- p-values;
- confidence intervals;
- effect sizes;
- correlations;
- test statistics.

No placeholder statistics are included in the research report.

---

16. Analysis Reproducibility

The final analysis should be reproducible from:

Raw Data
+
Cleaning Log
+
Analysis Dataset
+
Analysis Code
+
Analysis Plan

The repository therefore separates evidence, transformation, and interpretation.

18. Readiness Decision

The methodological and technical infrastructure required for empirical analysis is complete.

The project is therefore classified as:

«Analysis-ready, evidence-controlled research project.»

This classification means that the project can move from data collection and validation into empirical analysis as soon as the recorded observations satisfy the quality criteria.

It does not imply that an empirical effect has already been demonstrated.

---

19. Day 31 Conclusion

Day 31 completes the bridge between formal data collection and reproducible empirical analysis.

The project now separates four critical layers:

Research Design
        ↓
Recorded Evidence
        ↓
Data Processing
        ↓
Interpretation

This separation is essential for a credible Human Factors research artifact because it prevents the desired conclusion from influencing the underlying evidence.
