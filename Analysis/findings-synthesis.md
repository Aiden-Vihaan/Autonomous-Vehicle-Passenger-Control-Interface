Findings Synthesis

1. Purpose

The purpose of this analysis is to determine whether observed data provide evidence concerning the effect of passenger-facing explanations on:

- objective understanding,
- response efficiency,
- trust,
- cognitive workload,
- perceived understanding,
- task performance.

The analysis does not assume that more explanation is inherently better.

4. Trust

Trust is interpreted alongside comprehension.

High comprehension + appropriate trust
→ potentially calibrated interaction

High trust + poor comprehension
→ possible over-trust concern

Low trust + high comprehension
→ possible under-trust concern

These are interpretation frameworks, not assumptions about the observed data.
